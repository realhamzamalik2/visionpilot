# Recording the demo GIF

1. Install ScreenToGif (free): `winget install --id NickeManarin.ScreenToGif -e`
2. Start everything with `dev.ps1`, open http://localhost:3000, and set the browser to about 1280x800.
3. Record one take of about 20 seconds: pick the Korean menu sample, click a suggested question, let the trace
   stream, then hover the underlined phrases in the answer.
4. In the editor, cut idle waiting (keep the trace cards appearing), export as GIF at 12 fps and under 8 MB.
5. Save as `docs/demo.gif` and uncomment the image line at the top of the README.
