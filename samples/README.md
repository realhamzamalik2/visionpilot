# Sample media

Shown in the web app's sample gallery, grouped by folder (scenario). `manifest.json` sets titles and suggested
questions. Add your own as `samples/<scenario>/<file>`; scenarios with built-in copy are `retail`, `seoul` and
`classroom`.

Credits: `street_bus.jpg` and the frames of `street_pan.mp4` come from the Ultralytics sample assets (AGPL-3.0).
`korean_menu.jpg` was generated for this project.
